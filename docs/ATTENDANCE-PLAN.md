# Kalender kehadiran tahunan

> Pelaksana: superpowers:executing-plans, langsung di checkout ini. Pengguna menyetujui kalender GitHub dengan status harian, ringkasan, detail tanggal dan navigasi tahun. Tidak commit/push/deploy.

**Goal:** Menampilkan pola kehadiran pegawai dari data nyata, tanpa menganggap data kosong sebagai mangkir.

**Architecture:** Laravel/Inertia/React yang ada, tanpa library chart/dependency baru. AttendanceCalendar menghitung satu status per tanggal WIB, AttendanceRecords menyimpan pencatatan HR dengan versi, mutex akun → pegawai → catatan dan audit snapshot append-only. Tabel attendance_days unique employee/date berisi jadwal UTC dan waktu masuk/pulang UTC, toleransi menit, version, voided_at. attendance_events menyimpan snapshot sebelum/sesudah/alasan/actor UTC. Jadwal dan identitas tanggal tidak dapat diganti pada koreksi tanggal lain; tanggal lain memakai catatan sendiri. Pembatalan catatan menyimpan bukti/riwayat, pengaktifan kembali lewat koreksi beralasan.

**Keputusan implementasi:** Sumber mesin belum dipilih pengguna. Agar kalender dapat digunakan, fase ini menyediakan input manual Admin/Staf HR pada detail hari. Tidak membuat check-in pegawai, fingerprint, impor, GPS/selfie atau payroll. UI menyatakan sumber Dicatat HR; jam manual bukan bukti lokasi/keaslian mesin. Jadwal eksplisit per tanggal (termasuk Sabtu/Minggu bila HR mengisi), durasi >0 sampai24jam, boleh lintas tengah malam. Masuk/pulang lengkap nullable; pulang memerlukan masuk; semua punch tidak masa depan, pulang>=masuk, terkait tanggal kerja mulai pada tanggal tersebut (jam masuk boleh sehari sebelum/sesudah awal jadwal maksimal24jam, durasi hadir≤24jam). Hari sebelum bergabung ditolak. Jadwal masa depan boleh dicatat tanpa punch; tidak ada jadwal otomatis atau retroaktif dari pola kerja asumsi. Toleransi0–120menit, telat = ceil selisih aktual dari jam mulai; status telat jika selisih melewati toleransi.

**Status:** hijau hadir lengkap tepat waktu; kuning hadir lengkap terlambat; biru cuti/izin disetujui; ungu sakit disetujui; merah tanpa masuk sesudah akhir jadwal eksplisit; abu libur (akhir pekan/libur HR tanpa jadwal); garis kosong masa depan; arsiran perlu diperiksa (punch tidak lengkap setelah jadwal selesai, atau punch bertabrakan cuti); netral berbeda belum ada data / sedang berjalan / belum mulai / belum bergabung. Cuti membaca work_dates snapshot approved/cancel_pending; tidak mengirim alasan/berkas sakit/cuti. Cuti tanpa data absensi tetap tampil, pencatatan punch pada cuti ditandai konflik. Data tanpa jadwal tidak menambah denominator persentase; fase ini hanya jumlah hari, tidak skor produktivitas/ranking. Ringkasan tahun s.d. hari ini: hadir lengkap (=tepat+telat), tepat, telat, perlu diperiksa, tanpa keterangan. Tanggal masa depan dikecualikan; libur tanpa jadwal tidak dianggap absen. Tidak otomatis mengubah SP/gaji.

**UI & access:** /attendance portal own untuk employee/supervisor; /attendance/employees/{employee} HR atau supervisor anggota langsung aktif; Viewer ditolak. HR /attendance daftar pegawai cari/pagination15 → detail kalender. Tautan di detail pegawai/portal. Tahun2000–2100; semua tanggal pada tahun terpilih termasuk29Feb, Senin–Minggu vertikal dan minggu horizontal; padding non-tanggal bukan tombol. Detail hari ketika klik; arrowkeys bergerak harian/mingguan, satu tabstop, label tanggal/status, legenda pola bukan warna saja. Light/navy/font lama dipertahankan. Hscroll lokal di ponsel; status teks/detail selalu tersedia. Audit riwayat koreksi hanya HR dan pemilik, supervisor hanya waktu/status tim, tidak kontak/catatan pribadi.
